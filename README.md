# Moça do Bolo — MVP

Painel para centralizar e acompanhar os pedidos recebidos pelo iFood, 99Food e Keeta.

## Objetivo

Reduzir o tempo gasto alternando entre aplicativos e facilitar o controle da produção e das entregas.

## Usuárias

O sistema é pensado para a equipe da Moça do Bolo, formada por duas pessoas que dividem administração, produção, limpeza e logística.
